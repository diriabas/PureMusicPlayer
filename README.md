# Pure Music Player

Native Android music player starter for Huawei devices. Built with Kotlin, Jetpack Compose and AndroidX Media3.

## Build

GitHub Actions builds a debug APK on pushes, pull requests and manual workflow runs. Download `PureMusicPlayer-debug` from the Actions run's Artifacts section.

## Current scope

- Local audio library via MediaStore
- Runtime audio permission request
- Basic playback via ExoPlayer
- Dark UI

Background playback, media notification/session, playlists, equalizer and metadata editing are planned next.
